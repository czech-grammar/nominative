# Plural Formation Cheatsheet

All nominative plural patterns at a glance.

---

## The Big Picture

```
┌─────────────────────────────────────────────────┐
│           PLURAL FORMATION                      │
├─────────────────────────────────────────────────┤
│                                                 │
│  MASCULINE ANIMATE:                             │
│    Hard: -i (student → studenti)                │
│    Soft: -i (muž → muži)                        │
│    Or: -ové (pán → pánové)                      │
│                                                 │
│  MASCULINE INANIMATE:                           │
│    Hard: -y (hrad → hrady)                      │
│    Soft: -e (stroj → stroje)                    │
│                                                 │
│  FEMININE:                                      │
│    -a → -y (žena → ženy)                        │
│    -e → -e (růže → růže)                        │
│    cons → -i (kost → kosti)                     │
│                                                 │
│  NEUTER:                                        │
│    -o → -a (město → města)                      │
│    -e → -e (moře → moře)                        │
│    -í → -í (stavení → stavení)                  │
│                                                 │
└─────────────────────────────────────────────────┘
```

---

## Masculine Plurals

### Animate (Living Things)

| Singular | Plural | Pattern |
|:---------|:-------|:--------|
| student | student**i** | hard → -i |
| pán | pán**ové** | formal → -ové |
| muž | muž**i** | soft → -i |
| učitel | učitel**é** | -tel → -é |
| kluk | kluc**i** | k → c + i |
| Čech | Češ**i** | ch → š + i |
| doktor | doktor**i** | → -i |

### Inanimate (Non-Living Things)

| Singular | Plural | Pattern |
|:---------|:-------|:--------|
| hrad | hrad**y** | hard → -y |
| les | les**y** | hard → -y |
| stroj | stroj**e** | soft → -e |
| pokoj | pokoj**e** | soft → -e |

## Feminine Plurals

| Type | Singular | Plural | Pattern |
|:-----|:---------|:-------|:--------|
| -a | žena | žen**y** | -a → -y |
| -a | kniha | knih**y** | -a → -y |
| -a | škola | škol**y** | -a → -y |
| -e | růže | růž**e** | no change |
| -e | ulice | ulic**e** | no change |
| cons | kost | kost**i** | + -i |
| cons | věc | věc**i** | + -i |

## Neuter Plurals

| Type | Singular | Plural | Pattern |
|:-----|:---------|:-------|:--------|
| -o | město | měst**a** | -o → -a |
| -o | okno | okn**a** | -o → -a |
| -o | auto | aut**a** | -o → -a |
| -e | moře | moř**e** | no change |
| -e | pole | pol**e** | no change |
| -í | stavení | staven**í** | no change |

---

## Consonant Changes

Before **-i** in masculine animate plurals:

| Change | Example |
|:-------|:--------|
| **k → c** | kluk → kluci |
| **h → z** | Bůh → bozi |
| **ch → š** | Čech → Češi |
| **r → ř** | doktor → doktoři |

## Memory Tips

:::tip Animate vs. Inanimate
This distinction only matters for MASCULINE nouns:
- Living things (people, animals) = animate
- Objects, places = inanimate
:::

:::warning Watch the Consonant Changes
Before -i: k→c, h→z, ch→š, r→ř
- kluk → kluc**i** (not kluki!)
- Čech → Češ**i** (not Čechi!)
:::
