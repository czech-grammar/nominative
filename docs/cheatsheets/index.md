## Gender Quick Reference

| Ending | Gender | Examples |
|:-------|:-------|:---------|
| **-a** | Feminine | žena, kniha, škola |
| **-o** | Neuter | město, auto, okno |
| **-e** | Check! | moře (n), růže (f), soudce (m) |
| **-í** | Neuter | stavení, nádraží |
| **Consonant** | Usually Masculine | student, hrad, muž |

:::tip Exceptions
- Some -a nouns are masculine: táta, kolega, Honza
- Some consonant nouns are feminine: kost, věc, noc
:::

## Plural Quick Reference

### Masculine

| Type | Ending | Example |
|:-----|:-------|:--------|
| Animate hard | **-i** | student → studenti |
| Animate soft | **-i** | muž → muži |
| Inanimate hard | **-y** | hrad → hrady |
| Inanimate soft | **-e** | stroj → stroje |

### Feminine

| Type | Ending | Example |
|:-----|:-------|:--------|
| -a | **-y** | žena → ženy |
| -e | **-e** | růže → růže |
| consonant | **-i** | kost → kosti |

### Neuter

| Type | Ending | Example |
|:-----|:-------|:--------|
| -o | **-a** | město → města |
| -e | **-e** | moře → moře |
| -í | **-í** | stavení → stavení |

## Adjective Quick Reference

### Hard Adjectives

| Gender | Singular | Plural |
|:-------|:---------|:-------|
| Masc. | nov**ý** | nov**í**/é |
| Fem. | nov**á** | nov**é** |
| Neut. | nov**é** | nov**á** |

### Soft Adjectives

All forms: **cizí** (same everywhere)
