# Forming Nominative Plurals

Learn how to transform singular nominative nouns into their plural forms.

---

## Overview

Plural formation depends on:
1. **Gender** (masculine/feminine/neuter)
2. **Noun pattern** (hard/soft stem)
3. For masculine: **animate vs. inanimate**

---

## Masculine Plurals

### Masculine Animate (Living Things)

| Singular | Plural | Pattern |
|:---------|:-------|:--------|
| student | student**i** | Hard → -i |
| pán | pán**ové** | -ové ending |
| muž | muž**i** | Soft → -i |
| Čech | Češ**i** | ch → š + -i |
| člověk | lid**é** | Irregular |

:::tip Animate Plurals
Most animate masculine nouns take **-i** (with possible consonant changes) or **-ové** (more formal/respectful).
:::

### Common Animate Patterns

| Singular | Plural | Note |
|:---------|:-------|:-----|
| student | studenti | Regular |
| kluk | kluci | k → c |
| Čech | Češi | ch → š |
| hoch | hoši | ch → š |
| doktor | doktoři | r → ř |
| učitel | učitelé | -é ending |
| Němec | Němci | ec → ci |

### Masculine Inanimate (Non-Living Things)

| Singular | Plural | Pattern |
|:---------|:-------|:--------|
| hrad | hrad**y** | Hard → -y |
| les | les**y** | Hard → -y |
| stroj | stroj**e** | Soft → -e |
| pokoj | pokoj**e** | Soft → -e |
| dům | dom**y** | Vowel change |

## Feminine Plurals

### -a Feminines → -y

| Singular | Plural | Pattern |
|:---------|:-------|:--------|
| žena | žen**y** | -a → -y |
| kniha | knih**y** | -a → -y |
| škola | škol**y** | -a → -y |
| hora | hor**y** | -a → -y |

### Soft Feminines → -e

| Singular | Plural | Pattern |
|:---------|:-------|:--------|
| růže | růž**e** | No change |
| ulice | ulic**e** | No change |
| židle | židl**e** | No change |
| kancelář | kancelář**e** | + -e |

### Consonant Feminines → -i

| Singular | Plural | Pattern |
|:---------|:-------|:--------|
| kost | kost**i** | + -i |
| věc | věc**i** | + -i |
| noc | noc**i** | + -i |

---

## Neuter Plurals

### -o Neuters → -a

| Singular | Plural | Pattern |
|:---------|:-------|:--------|
| město | měst**a** | -o → -a |
| okno | okn**a** | -o → -a |
| auto | aut**a** | -o → -a |
| slovo | slov**a** | -o → -a |

### -e Neuters → -e

| Singular | Plural | Pattern |
|:---------|:-------|:--------|
| moře | moř**e** | No change |
| pole | pol**e** | No change |

### -í Neuters → -í

| Singular | Plural | Pattern |
|:---------|:-------|:--------|
| stavení | staven**í** | No change |
| nádraží | nádraž**í** | No change |

## Consonant Changes

Some consonants change before certain endings:

| Change | Example |
|:-------|:--------|
| k → c | kluk → kluci |
| h → z | Bůh → bozi |
| ch → š | Čech → Češi |
| r → ř | doktor → doktoři |
| g → z | dialog → dialogy (no change in inanimate) |

---

## Irregular Plurals

Some common nouns have irregular plurals:

| Singular | Plural | Meaning |
|:---------|:-------|:--------|
| člověk | **lidé** | person/people |
| dítě | **děti** | child/children |
| oko | **oči** | eye/eyes |
| ucho | **uši** | ear/ears |
| ruka | **ruce** | hand/hands |
| přítel | **přátelé** | friend/friends |
| bratr | **bratři/bratři** | brother/brothers |

## Practice

Form the nominative plural:

1. student (m. anim.) → ___
2. žena (f.) → ___
3. město (n.) → ___
4. hrad (m. inanim.) → ___
5. kniha (f.) → ___
6. auto (n.) → ___
7. učitel (m. anim.) → ___
8. kost (f.) → ___

<details>
<summary>**Answers**</summary>

1. student → **studenti**
2. žena → **ženy**
3. město → **města**
4. hrad → **hrady**
5. kniha → **knihy**
6. auto → **auta**
7. učitel → **učitelé**
8. kost → **kosti**

</details>

## Common Mistakes

:::warning Watch Out!
- Don't confuse animate and inanimate masculine plurals
  - ✅ studenti (animate → -i)
  - ✅ hrady (inanimate → -y)
- Remember consonant changes before -i
  - ✅ kluci (k → c)
  - ❌ kluki
:::
