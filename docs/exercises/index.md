## Quick Practice: Gender Identification

What gender is each noun?

1. kniha → ___
2. student → ___
3. město → ___
4. učitelka → ___
5. moře → ___

<details>
<summary>**Answers**</summary>

1. kniha → **feminine** (-a ending)
2. student → **masculine** (consonant ending)
3. město → **neuter** (-o ending)
4. učitelka → **feminine** (-a ending)
5. moře → **neuter** (-e ending, moře pattern)

</details>

## Quick Practice: Plural Formation

Form the nominative plural:

### Masculine

1. student → ___
2. hrad → ___
3. muž → ___
4. pokoj → ___
5. kluk → ___

<details>
<summary>**Answers**</summary>

1. student → **studenti** (animate, -i)
2. hrad → **hrady** (inanimate, -y)
3. muž → **muži** (animate soft, -i)
4. pokoj → **pokoje** (inanimate soft, -e)
5. kluk → **kluci** (animate, k → c + i)

</details>

### Feminine

1. žena → ___
2. kniha → ___
3. růže → ___
4. kost → ___
5. škola → ___

<details>
<summary>**Answers**</summary>

1. žena → **ženy**
2. kniha → **knihy**
3. růže → **růže** (no change)
4. kost → **kosti**
5. škola → **školy**

</details>

### Neuter

1. město → ___
2. auto → ___
3. moře → ___
4. okno → ___
5. stavení → ___

<details>
<summary>**Answers**</summary>

1. město → **města**
2. auto → **auta**
3. moře → **moře** (no change)
4. okno → **okna**
5. stavení → **stavení** (no change)

</details>

## Quick Practice: Adjective Agreement

Add the correct adjective ending:

1. nov___ student (m. sg.)
2. star___ kniha (f. sg.)
3. velk___ město (n. sg.)
4. mal___ studenti (m. anim. pl.)
5. krásn___ ženy (f. pl.)
6. nov___ města (n. pl.)

<details>
<summary>**Answers**</summary>

1. nov**ý** student
2. star**á** kniha
3. velk**é** město
4. mal**í** studenti
5. krásn**é** ženy
6. nov**á** města

</details>
