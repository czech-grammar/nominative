# Plural Formation Exercises

Practice forming nominative plurals.

---

## Set 1: Masculine Animate

Form the plural of these living masculine nouns:

1. student → ___
2. učitel → ___
3. muž → ___
4. pán → ___
5. kluk → ___
6. Čech → ___
7. doktor → ___
8. přítel → ___

<details>
<summary>**Answers**</summary>

1. student → **studenti**
2. učitel → **učitelé**
3. muž → **muži**
4. pán → **pánové** (or páni)
5. kluk → **kluci** (k → c)
6. Čech → **Češi** (ch → š)
7. doktor → **doktoři** (r → ř)
8. přítel → **přátelé**

</details>

## Set 7: Irregular Plurals

What are the plurals of these common irregular nouns?

1. člověk → ___
2. dítě → ___
3. oko → ___
4. ucho → ___
5. ruka → ___
6. bratr → ___

<details>
<summary>**Answers**</summary>

1. člověk → **lidé** (completely different!)
2. dítě → **děti**
3. oko → **oči** (not oka!)
4. ucho → **uši** (not ucha!)
5. ruka → **ruce** (not ruky!)
6. bratr → **bratři**

These must be memorized!

</details>

## Tips

:::tip Animate vs. Inanimate
For masculine nouns, always ask: Is it alive?
- **Alive** (animate): student → studenti (-i)
- **Not alive** (inanimate): hrad → hrady (-y)
:::

:::warning Consonant Changes
Before -i: k→c, h→z, ch→š, r→ř
Don't forget these!
:::
