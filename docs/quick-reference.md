# Nominative Quick Reference

All nominative patterns on one page.

---

## The Basics

| Question | Answer |
|:---------|:-------|
| **Czech name** | Nominativ (1. pád) |
| **Question** | Kdo? Co? (Who? What?) |
| **Function** | Subject, dictionary form |

---

## Gender at a Glance

| Gender | Typical Endings | Examples |
|:-------|:----------------|:---------|
| **Masculine** | consonant | student, pán, muž, hrad |
| **Feminine** | -a, -e, consonant | žena, růže, kost |
| **Neuter** | -o, -e, -í | město, moře, stavení |

---

## Plural Formation

### Masculine

| Type | Singular → Plural | Example |
|:-----|:------------------|:--------|
| Animate hard | → **-i** | student → studenti |
| Animate (formal) | → **-ové** | pán → pánové |
| Animate soft | → **-i** | muž → muži |
| Inanimate hard | → **-y** | hrad → hrady |
| Inanimate soft | → **-e** | stroj → stroje |

### Feminine

| Type | Singular → Plural | Example |
|:-----|:------------------|:--------|
| -a | → **-y** | žena → ženy |
| -e | → **-e** | růže → růže |
| consonant | → **-i** | kost → kosti |

### Neuter

| Type | Singular → Plural | Example |
|:-----|:------------------|:--------|
| -o | → **-a** | město → města |
| -e | → **-e** | moře → moře |
| -í | → **-í** | stavení → stavení |

---

## Adjective Endings

### Hard Adjectives (nový)

|  | Masculine | Feminine | Neuter |
|:-|:----------|:---------|:-------|
| **Sg.** | nov**ý** | nov**á** | nov**é** |
| **Pl.** | nov**í**/é | nov**é** | nov**á** |

### Soft Adjectives (cizí)

All forms: **cizí** (same for all genders and numbers)

## Memory Chart

```
┌──────────────────────────────────────────────────────────┐
│                NOMINATIVE OVERVIEW                       │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  GENDER IDENTIFICATION:                                  │
│    -A → Feminine (žena, kniha)                           │
│    -O → Neuter (město, auto)                             │
│    Consonant → Usually Masculine (student, hrad)         │
│                                                          │
│  PLURAL RULES:                                           │
│    Masc. animate: -i (studenti) or -ové (pánové)         │
│    Masc. inanimate: -y (hrady) or -e (stroje)            │
│    Feminine -a: -y (ženy)                                │
│    Neuter -o: -a (města)                                 │
│                                                          │
│  ADJECTIVES:                                             │
│    Hard: -ý (m), -á (f), -é (n) singular                 │
│    Soft: -í for everything                               │
│                                                          │
└──────────────────────────────────────────────────────────┘
```
