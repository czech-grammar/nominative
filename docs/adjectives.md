# Adjective Agreement in Nominative

Adjectives must match their nouns in **gender**, **number**, and **case**.

---

## The Basic Rule

In nominative, adjectives take these endings:

| Gender | Singular | Plural |
|:-------|:---------|:-------|
| Masculine | -**ý** / -**í** | -**í** / -**é** |
| Feminine | -**á** / -**í** | -**é** / -**í** |
| Neuter | -**é** / -**í** | -**á** / -**í** |

---

## Hard Adjectives (-ý/-á/-é)

Most adjectives follow the **hard** pattern:

### Singular

| Gender | Ending | Example |
|:-------|:-------|:--------|
| Masculine | nov**ý** | nový student |
| Feminine | nov**á** | nová kniha |
| Neuter | nov**é** | nové město |

### Plural

| Gender | Ending | Example |
|:-------|:-------|:--------|
| Masc. Animate | nov**í** | noví studenti |
| Masc. Inanimate | nov**é** | nové hrady |
| Feminine | nov**é** | nové knihy |
| Neuter | nov**á** | nová města |

---

## Soft Adjectives (-í)

Some adjectives have the same ending for all genders:

### Singular & Plural

| Form | Example |
|:-----|:--------|
| Masc. sg. | ciz**í** muž |
| Fem. sg. | ciz**í** žena |
| Neut. sg. | ciz**í** město |
| All plurals | ciz**í** lidé/ženy/města |

### Common Soft Adjectives

| Czech | English |
|:------|:--------|
| cizí | foreign |
| jarní | spring |
| letní | summer |
| podzimní | autumn |
| zimní | winter |
| dnešní | today's |
| včerejší | yesterday's |

---

## Full Paradigm: Hard "nový"

```
┌─────────────────────────────────────────────────┐
│           HARD ADJECTIVE: NOVÝ                  │
├─────────────────────────────────────────────────┤
│                SINGULAR                         │
│  Masculine:    nov-Ý student                    │
│  Feminine:     nov-Á kniha                      │
│  Neuter:       nov-É město                      │
├─────────────────────────────────────────────────┤
│                PLURAL                           │
│  Masc. anim.:  nov-Í studenti                   │
│  Masc. inan.:  nov-É hrady                      │
│  Feminine:     nov-É knihy                      │
│  Neuter:       nov-Á města                      │
└─────────────────────────────────────────────────┘
```

---

## Full Paradigm: Soft "cizí"

```
┌─────────────────────────────────────────────────┐
│           SOFT ADJECTIVE: CIZÍ                  │
├─────────────────────────────────────────────────┤
│                SINGULAR                         │
│  Masculine:    ciz-Í muž                        │
│  Feminine:     ciz-Í žena                       │
│  Neuter:       ciz-Í město                      │
├─────────────────────────────────────────────────┤
│                PLURAL                           │
│  All genders:  ciz-Í (lidé/ženy/města)          │
└─────────────────────────────────────────────────┘
```

---

## Adjective Position

In Czech, adjectives usually come **before** the noun:

| Czech | English |
|:------|:--------|
| **krásná** žena | beautiful woman |
| **velké** město | big city |
| **dobrý** přítel | good friend |

---

## Examples in Sentences

| Czech | English |
|:------|:--------|
| **Mladý** student studuje. | The young student studies. |
| **Stará** kniha je zajímavá. | The old book is interesting. |
| **Nové** auto je drahé. | The new car is expensive. |
| **Noví** studenti přišli. | The new students came. |

## Practice

Add the correct adjective ending:

1. dobr___ člověk (m. sg.)
2. krásn___ žena (f. sg.)
3. velk___ okno (n. sg.)
4. star___ hrady (m. inan. pl.)
5. nov___ studenti (m. anim. pl.)
6. mal___ děti (n. pl.)

<summary>**Answers**</summary>

1. dobr**ý** člověk
2. krásn**á** žena
3. velk**é** okno
4. star**é** hrady
5. nov**í** studenti
6. mal**á** děti (děti = neuter plural)
